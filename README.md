# 아마추어 무선 표준 회로 기호 도감 & FCC 실전 회로 (ham-circuit-handbook)

FCC 아마추어 무선 시험 문제집에 나오는 회로 기호와 회로도를 한 페이지에 모은 편람입니다. 기호마다 원어와 쓰임을, 회로마다 실체 배선도·표준 회로도·동작 순서·부품별 역할을 함께 적었습니다.

## 구성

1. 회로 기호 36종 — 기초 소자 16종, FET 구분(Figure E6-1) 6종, 특수 다이오드·사이리스터(E6-2) 8종, 논리 게이트·증폭 기호(E6-3) 6종
2. Technician 회로 — T-1 트랜지스터 스위칭, T-2 리니어 직류 전원, T-3 T형 안테나 튜너 (실체 배선도와 회로도 비교)
3. General 회로 — G7-1 VFO 발진·버퍼 증폭 (부품 1~11번)
4. Extra 회로 — E7-1 공통 이미터 증폭기, E7-2 직렬 패스 레귤레이터, E7-3 반전 연산 증폭기

맨 위의 목차 버튼을 누르면 그 장으로 이동하고, 「기호·부품 찾기」 칸에 제너·바랙터·MOSFET 같은 말을 넣으면 해당 기호와 회로만 남습니다. FCC 문제집 원본 도면 10장(T-1~T-3, G7-1, E6-1~E6-3, E7-1~E7-3)은 `img/` 폴더에 같은 크기(1200×800)로 맞춰 두었고, 기호 카드와 실체 부품 배선도는 페이지 안의 SVG입니다.

## 게시

주소: https://kooking0-jh.github.io/ham-circuit-handbook/

1. GitHub에서 새 저장소 `ham-circuit-handbook` 생성 (Public)
2. `index.html`, `README.md`, `tistory-embed.html`과 `img` 폴더(그림 10장)를 업로드 — 압축을 푼 폴더 안의 파일과 `img` 폴더를 업로드 화면에 한꺼번에 끌어 놓으면 폴더째 올라갑니다
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소 접속 확인

티스토리에는 `tistory-embed.html`의 코드를 글의 HTML 모드에 붙여 넣습니다(높이 자동 맞춤, 목차 링크 이동). 블로그(iframe) 삽입 규약은 antenna-types 규약을 그대로 씁니다.
